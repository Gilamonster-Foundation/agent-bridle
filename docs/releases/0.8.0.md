# agent-bridle v0.8.0

**API-breaking security release.** v0.8.0 gives a consumer a shared, backend-agnostic
enforcement boundary that expresses and enforces a **per-axis minimum enforcement
strength**, and **refuses before hostile execution** whenever the required per-axis
witness cannot be supplied.

The invariant:

```
restricted axis
  + required enforcement strength
  + actual backend witness below requirement (or MISSING)
  = REFUSE BEFORE EXECUTION
```

Never `missing/weak backend → Advisory/Noop fallback → host execution`.

## Headline: per-axis `EnforcementFloor`

`ToolContext` previously carried one scalar `AxisEnforcement strength_floor`. It now
carries a first-class per-axis `EnforcementFloor`, pairing 1:1 with `EnforcementReport`:

```rust
pub struct EnforcementFloor {
    pub fs_read:  AxisEnforcement,
    pub fs_write: AxisEnforcement,
    pub exec:     AxisEnforcement,
    pub net:      AxisEnforcement,
}
```

Semantics (`unenforceable_axis(effective, active, floor)`), driven by the **Caveat
restriction**, not the report's `Option`:

- `Scope::All` (unrestricted) axis → no obligation.
- restricted axis with a witness `>= floor[axis]` → admit.
- restricted axis with a witness **below** `floor[axis]` → **refuse**.
- restricted axis with **no** report witness → **refuse** (missing report data is
  never vacuous success).

Presets: `EnforcementFloor::DEFAULT` (fs = Kernel, exec/net = Advisory — the historic
default), `EnforcementFloor::CONFINED` = `{fs_read: Kernel, fs_write: Kernel, net:
Kernel, exec: Interceptor}`, `uniform(_)`, `from_scalar(_)`. The contract names no
platform (`Kernel`/`Interceptor`/`Advisory`, never `Landlock`/`Seatbelt`/`AppContainer`).

The three objects stay distinct: **Caveats** = *what* authority; **EnforcementFloor** =
*how strongly* restricted authority must be bounded; **EnforcementReport** = *what
strength* the backend delivered. Acceptance composes them:
`for each restricted axis: report[axis] >= floor[axis] OR REFUSE`.

## Breaking changes

| v0.7 | v0.8 |
|------|------|
| `AxisStrengthFloor` | **`EnforcementFloor`** (fields split: `filesystem` → `fs_read` + `fs_write`) |
| `Gate::with_strength_floor(AxisEnforcement)` | kept (scalar compat, maps via `from_scalar`); add `Gate::with_enforcement_floor(EnforcementFloor)` |
| `Registry::dispatch_with_strength_floor(..)` | kept (scalar compat); add `dispatch_with_enforcement_floor(.., EnforcementFloor)` |
| — | add `dispatch_oneshot_with_enforcement_floor(.., EnforcementFloor)` |
| `Tool::invoke -> ToolResult<Value>` | unchanged; new defaulted `Tool::invoke_accounted -> ToolResult<Invocation>` (`Invocation::{Ran, Denied}`) used by the registry for call-budget accounting |
| `Registry::dispatch(name, args, &Caveats)` | `dispatch(name, args, &Grant)` — mint via `Registry::mint_grant(caveats)`; reuse the grant so `max_calls` persists across dispatches |
| — | `Registry::dispatch_oneshot(name, args, &Caveats)` — stateless, no persistent ledger row |
| `UnenforceableAxis.actual: AxisEnforcement` | `Option<AxisEnforcement>` (`None` = restricted axis with no witness) |
| trusted-worker protocol v1 | **v2** (carries the per-axis floor) |
| `WebFetchTool` (unit struct, `Copy`) | struct with an immutable `net_private` ceiling; `new()`/`default()` = `Scope::none()`, `with_private_hosts(scope)` opens it. **Not** a Caveats axis, **not** per-`Grant` attenuable. |

## Migration (downstream consumer, e.g. Newt)

```rust
use agent_bridle::{EnforcementFloor, Registry};

// Confined lane: require kernel fs/net, interceptor exec — refuse if unmet.
let floor = EnforcementFloor::CONFINED;
let grant = registry.mint_grant(caveats);                                   // persistent budget
registry.dispatch_with_enforcement_floor(name, args, &grant, floor).await?;
// one-shot (no persistent ledger row):
registry.dispatch_oneshot_with_enforcement_floor(name, args, &caveats, floor).await?;
```

Switch confined lanes from a blanket scalar `Kernel` floor to `CONFINED`: the scalar
`Kernel` demanded Kernel on **every** axis (which wrongly rejects the exec axis on
interceptor-exec backends like Landlock); `CONFINED` requires Kernel fs/net but accepts
Interceptor exec — the correct floor.

## Known residuals (explicit, not silently green)

- **agent-bridle#318** — macOS Seatbelt: a confined granted `sh` does not run its
  also-granted `sleep` descendant under the current CI runner (returns instantly,
  `timed_out:false`); the two AB-006 timeout tests are `#[cfg_attr(target_os =
  "macos", ignore)]` (asserted on Linux). **The macOS timeout-kill property is
  unverified-in-CI** pending an on-device root cause. Do not read the quarantine as
  macOS readiness.
- **agent-bridle#319** — the spawn boundary is CLOEXEC-only: `ConfinedCommand`
  delegates env explicitly but does not close ambient FDs, so a non-CLOEXEC parent
  descriptor is inherited by the child. The explicit `close_range` fix needs `unsafe`
  (core is `#![forbid(unsafe_code)]`) → a launcher-crate follow-up. A contract
  requiring stronger-than-CLOEXEC descriptor hygiene must account for this.
