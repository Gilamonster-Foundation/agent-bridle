## Notes

- The inherited-HANDLE result is a Windows process-creation property, not an AppContainer DACL denial. The confined child receives stdio handles via an explicit handle list and does not receive other inheritable launcher handles.
- `cmd.exe` and PowerShell descendant routes do not have identical ability to execute the staged helper from the AppContainer. The theorem records the observed route behavior instead of generalizing from one shell to the other.
